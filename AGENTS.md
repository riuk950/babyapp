# AGENTS.md — babyapp

## Proyecto
aplicación móvil desarrollada en flutter, bonita y práctica, diseñada para madres con niños de 0 a 5 años. El objetivo es proporcionar una guía rápida y accesible con información esencial sobre crianza directamente en sus teléfonos celulares.

## Comandos
- Ejecutar: flutter run
- Instalar Dependencias: flutter pub get
- Tests: flutter test

## Estilo y convenciones
- Flutter 3.44.0+
- Dart 3.12.0+
- Identificadores en ingles: mensajes de usuario en español
